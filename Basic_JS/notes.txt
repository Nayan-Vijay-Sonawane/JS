1. Function: 

Function is a block of code to perform a specific task

Types: 

Function Statment or Function Declaration
function a() {
    console.log("a called");
};

// Function Expression
// Assign a function to variable
const b = function(){
    console.log("b called");
};

// Arrow Function
// Just a shorter version of function (concise version)
const num = n => n*n;
console.log(num(5));

function getExp(x, y){
    let ans = x**y;
    return ans;
}
console.log(getExp(2, 10));

// Arrow
const letExp = (x, y) => {
    let ans = x**y;
    return ans;
}
console.log(getExp(2, 10));

// Immediately invoked Function Expression (IIFE)
// They are immediately inovoked after the declaration
const result = (function(){
    let x = 5;
    let y = 10;
    return x + y;
})();

console.log(result);


Notes : 

Scopes -  
    where this can be accessed 
    {
        let x = 10;
    }
    console.log(x); // error
    x exists only in inside the block, not outside it.
    - Block Scope -> code inside {} like in loops, if, etc.
    - Function Scope -> Code inside a function 
        let and const follow block Scope
        var ignores block scope which leads to bugs

Dynamic typing - 
    It means 
    let value = 10;
    value = "Hello";
    The variable isn't permanently decalred as 'number', the value has a type

Hoisting - 
    JS prepares memory before running code
    It moves all declarations to the top called hoisting
    - var is hoisted and set to undefined
    - let and const are hoisted but not initialized so accessing them early gives ReferenceError
    eg. 
        console.log(a);     // undefined
        var a = 10; 

        console.log(b);     // ReferenceError
        let b = 20;

Loose vs Strict equality -
    == -> compares value with type conversion
    === -> compares value + type (no conversion)

Typeof - 
    typeof "Nayan"      -> String
    typeof 90           -> number
    typeof true         -> boolean
    typeof undefined    -> undefined
    typeof null         -> object (known bug)
    typeof []           -> object
    typeof {}           -> object
    typeof function()   -> function


Ternary operator -
    shorthand of if...else
    condition ? valueIfTrue : valueIfFalse
    eg.
        const score = 80;
        const grade = score > 50 ? "Pass" : "Fail";

Control flow - 
    - early return pattern : 
        used in functions to exit early if some condition falls

Loops -
    - for -> best for numbers/indexes
    - for-of -> for array values
    - for-in -> for object keys
    - while -> for unpredictable conditions

Functions - 
    function greet(name){
        console.log("hello " + name);
    };
    greet("Nayan");
    - name is a parameter
    - Nayan is the argument

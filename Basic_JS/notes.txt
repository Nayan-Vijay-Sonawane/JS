1. Function: 

Function is a block of code to perform a specific task

Types: 

Function Statment or Function Declaration
function a() {
    console.log("a called");
};

// Function Expression
// Assign a function to variable
const b = function(){
    console.log("b called");
};

// Arrow Function
// Just a shorter version of function (concise version)
const num = n => n*n;
console.log(num(5));

function getExp(x, y){
    let ans = x**y;
    return ans;
}
console.log(getExp(2, 10));

// Arrow
const letExp = (x, y) => {
    let ans = x**y;
    return ans;
}
console.log(getExp(2, 10));

// Immediately invoked Function Expression (IIFE)
// They are immediately inovoked after the declaration
const result = (function(){
    let x = 5;
    let y = 10;
    return x + y;
})();

console.log(result);


Notes : 

Scopes -  
    where this can be accessed 
    {
        let x = 10;
    }
    console.log(x); // error
    x exists only in inside the block, not outside it.
    - Block Scope -> code inside {} like in loops, if, etc.
    - Function Scope -> Code inside a function 
        let and const follow block Scope
        var ignores block scope which leads to bugs

Dynamic typing - 
    It means 
    let value = 10;
    value = "Hello";
    The variable isn't permanently decalred as 'number', the value has a type

Hoisting - 
    JS prepares memory before running code
    It moves all declarations to the top called hoisting
    - var is hoisted and set to undefined
    - let and const are hoisted but not initialized so accessing them early gives ReferenceError
    eg. 
        console.log(a);     // undefined
        var a = 10; 

        console.log(b);     // ReferenceError
        let b = 20;
